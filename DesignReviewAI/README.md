# DesignReviewAI — 설계도서 자동 검토 프로그램

설계도서(PDF)를 업로드하면 Claude API가 전체 페이지를 읽고, 페이지별 검토·수량/규격
정합성 검증·구조검토·공사비 영향·근거기준까지 자동으로 정리한 검토 보고서(.xlsx)를
생성하는 프로그램입니다.

ChatGPT에 설계도서를 올렸을 때 나온 "산양일반산업단지 검토 결과" 형식의 엑셀(6개
시트: 종합요약 / 페이지별검토 / 정합성검증 / 공사비영향 / 구조검토 / 기준참고)을
매번 채팅으로 반복하지 않고, 명령 한 줄로 동일한 구조의 보고서를 만들기 위해
작성했습니다.

## 동작 방식

1. **PDF 추출** (`pdf_extract.py`) — PyMuPDF로 페이지별 텍스트를 추출합니다. 텍스트가
   거의 없는 페이지(도면, 스캔본 등)는 페이지 이미지를 함께 준비해 비전 분석에
   사용합니다.
2. **1차 추출** (`analyze.extract_all_pages`) — 여러 페이지를 배치로 묶어 Claude에게
   보내고, 각 페이지의 구분·핵심 발췌·수량/규격 수치를 구조화된 JSON으로 받습니다.
3. **교차분석** (`analyze.run_cross_analysis`) — 전체 페이지 1차 추출 결과를 한 번에
   Claude에게 주고, 서로 다른 페이지 간 수량/규격 불일치(정합성 이슈), 구조계산
   입력값 검토, 공사비 영향, 누락 물량, 관련 설계기준을 도출합니다.
4. **판정 확정** (`analyze.finalize_page_reviews`) — 도출된 이슈 레지스트리를 반영해
   각 페이지의 최종 판정(승인보류/재계산/중대보완/조건부확인/일반보완/확인/공백)과
   세부 검토결과·요구조치를 배치로 확정합니다.
5. **엑셀 생성** (`xlsx_builder.build_workbook`) — 결과를 업로드하신 템플릿과 동일한
   6개 시트 구조로 저장합니다. 판정 카운트(`COUNTIF`), 수량차·공사비 영향
   (`=C-B`, `=D*F`), 확정 항목 합계(`SUMIFS`) 등은 하드코딩 없이 수식으로 계산되므로
   엑셀에서 값을 바꾸면 자동 재계산됩니다.

## 설치

```bash
cd DesignReviewAI
python3 -m venv .venv && source .venv/bin/activate   # 선택
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
```

## 사용법

```bash
python -m design_review.cli \
  --input /path/to/설계도서.pdf \
  --output /path/to/검토결과.xlsx \
  --project-name "산양일반산업단지" \
  --review-scope "PDF 236쪽 전체: 설계설명서·일반시방서·내역서·단가/일위대가·견적·수량산출서·도면·구조계산서"
```

주요 옵션:

| 옵션 | 설명 |
|---|---|
| `--model` | 사용할 Claude 모델 (기본값: `claude-sonnet-5`) |
| `--batch-size` | 1차 추출 시 한 번에 묶어 보낼 페이지 수 (기본값 4). 도면이 많으면 줄이세요. |
| `--cache-dir` | 1차 추출 결과를 저장할 캐시 폴더 (기본값 `.design_review_cache`). 같은 PDF를 다시 돌릴 때 API 호출을 건너뜁니다. |
| `--no-cache` | 캐시를 무시하고 처음부터 다시 추출 |
| `--max-pages` | 앞쪽 N페이지만 처리 (파이프라인 점검용) |

## 출력 시트 구조

| 시트 | 내용 |
|---|---|
| 종합요약 | 판정 현황 집계(수식), 핵심 승인조건 Top 10, 공사비·수량 핵심, 종합판정, 검토 한계 |
| 페이지별검토 | 페이지 1쪽씩: 구분·원문 식별·검토 초점·판정·세부 검토결과·요구조치·관련쪽·이슈ID |
| 정합성검증 | 서로 다른 페이지 간 수량/규격 불일치 이슈 레지스트리 (ID, 기준1, 기준2, 차이, 비용연계) |
| 공사비영향 | 항목별 현재/검토 수량, 수량차·공사비 영향(수식), 누락 물량 별도 표 |
| 구조검토 | 시설·부위별 구조계산 입력값이 도면과 일치하는지 판정 |
| 기준참고 | 관련 KDS/KCS/법령 등 참고자료. URL을 확신할 수 없는 항목은 비워두고 "확인 필요"로 표시합니다. |

## 중요한 한계

- **AI 검토는 설계도서 내부 정합성 검토이며 구조 안전성의 최종 확인이 아닙니다.**
  현장조사·지반조사·원본 구조해석 파일·제조사 성능시험 자료는 반영되지 않으므로,
  책임기술자의 최종 확인을 대체하지 않습니다. (엑셀 종합요약 시트 하단에 이 문구가
  자동으로 포함됩니다.)
- **기준참고 시트의 URL은 검증되지 않았을 수 있습니다.** Claude가 확신하지 못하는
  URL은 비워두도록 지시했지만, 실제 발행 여부·최신 개정판 여부는 반드시 직접
  확인해야 합니다.
- **236쪽 규모 문서는 API 호출이 많습니다.** 배치 크기(`--batch-size`)와 페이지 수에
  비례해 비용·시간이 늘어납니다. `--cache-dir`로 1차 추출 결과를 캐싱해 재실행 비용을
  줄이세요.
- 도면처럼 텍스트가 거의 없는 페이지는 이미지를 함께 전달(비전 분석)하지만, 손글씨나
  저해상도 스캔은 인식률이 떨어질 수 있습니다.

## 프로젝트 구조

```
DesignReviewAI/
├── requirements.txt
├── README.md
└── src/design_review/
    ├── config.py        # 판정 등급, 색상, 기본 모델/배치 설정
    ├── schemas.py        # 데이터클래스 + Claude tool-use JSON 스키마
    ├── pdf_extract.py     # PyMuPDF 기반 페이지 텍스트/이미지 추출
    ├── llm_client.py      # Claude API 호출 래퍼 (재시도 포함)
    ├── analyze.py         # 3단계 분석 파이프라인 오케스트레이션
    ├── xlsx_builder.py    # 6시트 엑셀 보고서 생성 (수식 기반)
    └── cli.py             # 커맨드라인 진입점
```
